# MusicWeather Frontend

Vue.js frontend for **MusicWeather**, a personal music and weather tracking application.

The frontend provides visualizations and dashboards for listening activity, artists, and weather data collected by the backend API.

## Technologies

* Vue 3
* Vite
* Axios
* Chart.js
* Vue-Chartjs
* CSS

## Features

* Listening activity heatmap
* Artists statistics and rankings
* Weather dashboard
* Average temperature chart
* Historical weather data
* Date filtering
* Listening statistics

## Installation

Clone the repository and install the dependencies:

```bash
npm install
```

## Development

Start the development server:

```bash
npm run dev
```

The application will normally be available at:

```text
http://localhost:5173
```

## Backend

The frontend communicates with the MusicWeather FastAPI backend https://github.com/i-marasco/MusicWeather-backend.

Make sure the backend is running before using the application.

Backend API:

```text
http://127.0.0.1:8000
```
